# Couple Guild V0.3.5

V0.3.5 adds shared couple rewards on top of V0.3.4.

- Supabase `couple_rewards`
- Create custom couple voucher/reward
- Shared reward list across both phones
- Redeem available rewards through `redeem_couple_reward`
- Realtime refresh plus database fallback
- Keeps V0.3.4 shared guild home, V0.3.3 Realtime, V0.3.2 shared tasks, and V0.3.1 shared player world


## V0.3.5 UX
- Supabase URL / Anon Key saved in localStorage and reused for automatic reconnect.
- Touch-device feature panels use full-screen workspaces to avoid obscuring the game.
- Task, pet, shop and other modal features expand to the full viewport on touch devices.
