# Couple Guild V0.4.4

## Reference RPG Scene Rebuild

This version pushes the world scene toward the supplied RPG reference composition rather than only matching HUD colors.

### Visual targets
- illustrated central town plaza
- quest board centered in the upper-middle
- shop on upper-right
- guild house on upper-left
- fountain on lower-right
- river and bridge/waterfront on left
- signpost, benches, lamps, flower beds, trees and foreground foliage
- richer layered colors, shadows and highlights
- keep the existing landscape camera-based world and gameplay logic

### Gameplay logic
No Supabase, task, cat, multiplayer, or interaction system was intentionally removed.
